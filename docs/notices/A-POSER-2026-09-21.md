# Ce qu'il reste a poser a la main -- 21 septembre 2026

Trois choses sont ecrites et deployees mais **dormantes** : elles
attendent une action dans Supabase ou dans Vercel, que je ne peux pas
faire a ta place. Tant qu'elles ne sont pas posees, rien ne casse : la
page des parents dit simplement « lien inconnu », et les notifications
ne sonnent pas.

A faire dans l'ordre. Compte vingt minutes.

---

## 1. L'espace des parents (a coller dans Supabase)

**Ou** : Supabase -> ton projet -> SQL Editor -> New query -> coller ->
Run.

**Quoi** : le contenu entier de

    sql/migrations/MIGRATION-2026-09-21-espace-des-parents.sql

Ce fichier ajoute une colonne aux dossiers de l'ecole, tire un lien
personnel pour chaque famille, et cree la fonction qui rend le dossier.
Il peut etre relance sans risque.

**Si l'editeur refuse `gen_random_bytes`**, lance d'abord ceci, puis
recolle le fichier :

    create extension if not exists pgcrypto with schema extensions;

### Les liens a envoyer aux familles

Une fois la migration passee, lance cette requete : elle rend un
tableau avec le nom de l'enfant, le responsable, son telephone et le
lien a lui envoyer sur WhatsApp.

    select child_first_name || ' ' || child_last_name as enfant,
           guardian_name   as responsable,
           guardian_phone  as telephone,
           'https://www.baobabsbasketclub.com/parent/' || parent_jeton as lien
      from public.academy_registrations
     where parent_jeton is not null
       and status in ('essai','inscrite','en_pause')
     order by child_last_name;

Le bouton **Download CSV** de Supabase te sort le tout en tableur.

**Ce lien vaut comme une cle** : qui l'a, voit le dossier. C'est le
meme principe que les liens de collecte des joueuses. Pour en couper un
(une famille qui l'aurait partage), regenere-le :

    update public.academy_registrations
       set parent_jeton = encode(gen_random_bytes(24),'hex'),
           parent_jeton_le = now()
     where reference = 'BBC-2026-0042';

L'ancien lien cesse de fonctionner a la seconde.

**Ce que la famille voit** : le nom de l'enfant, ce qui reste a regler,
le mois par mois de la saison, et la liste de ce qui a ete verse. Rien
d'autre : ni sante, ni notes internes, ni telephone, ni le dossier du
voisin.

## 3. Trois reglages dans Vercel

**Ou** : vercel.com -> le projet -> Settings -> Environment Variables ->
Add New. Choisis **Production** pour chacune, puis **Redeploy** le
dernier deploiement (sans quoi les nouvelles valeurs ne sont pas lues).

| Nom | Valeur |
|---|---|
| `BBC_VAPID_PRIVEE` | dans `archives/secrets/vapid-2026-09-21.txt` |
| `BBC_NOTIF_SECRET` | dans le meme fichier |
| `SUPABASE_SERVICE_KEY` | Supabase -> Settings -> API -> `service_role` |

Ce fichier de secrets **n'est pas dans le depot** (le depot est public).
Il vit seulement sur ton ordinateur. Ne le colle nulle part ailleurs :
une cle montree est une cle perdue, il faudrait tout regenerer.

`service_role` passe outre toutes les regles de securite de la base.
Elle ne doit jamais se retrouver dans une page du site -- seulement
dans Vercel, cote serveur.

## Ce qui ne se declenche pas encore tout seul

Les notifications savent partir, mais **rien ne les declenche
automatiquement**. C'est volontaire : decider quand le club a le droit
de faire sonner le telephone des gens est ta decision, pas la mienne.
Quand tu l'auras tranchee (coup d'envoi ? resultat ? convocations ?),
je branche le declencheur.
