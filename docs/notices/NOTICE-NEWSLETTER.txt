BAOBABS BASKET CLUB — Envoi de la newsletter
============================================
Mise en place : 5 minutes si l'e-mail de confirmation est déjà installé
(même compte Brevo, mêmes secrets).

ÉTAPE 1 — LA BASE
  Supabase → SQL Editor → exécutez sql/migrations/MIGRATION-newsletter.sql
  (le journal des envois).

ÉTAPE 2 — LA FONCTION
  Supabase → Edge Functions → Deploy a new function
    Nom EXACT :  envoi-newsletter
    Collez tout le contenu de  supabase/functions/envoi-newsletter/index.ts  → Deploy.
  Les secrets BREVO_API_KEY / BBC_SENDER_EMAIL sont déjà en place si
  vous avez suivi NOTICE-EMAIL.txt. Sinon, faites d'abord ses étapes 1-2.

ÉTAPE 3 — TESTER SANS RISQUE
  Admin → Newsletter :
  1. Écrivez un sujet et un message.
  2. Mettez VOTRE adresse dans « M'envoyer un test » → seul vous recevez,
     avec [TEST] devant le sujet.
  3. Quand c'est bon : « Envoyer à tous » (une confirmation est demandée).

BON À SAVOIR
  - Chaque personne reçoit son propre e-mail : personne ne voit la liste.
  - Deux envois réels à moins de 10 minutes d'écart sont refusés
    (protection contre le double-clic).
  - Le pied de l'e-mail invite à répondre « STOP » pour se désinscrire :
    supprimez alors l'adresse dans Messages → Newsletter.
  - Brevo gratuit = 300 e-mails/jour : au-delà de 300 inscrits, l'envoi
    doit être étalé ou le compte passé en offre payante.
